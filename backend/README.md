# Backend

API REST en Node.js con Express.

Módulos previstos (apartado 1.7 del informe):

- usuarios — perfiles, roles y sesiones
- currículums — CRUD, versionado y exportación
- postulaciones — ofertas, requisitos y estados
- entrevistas — preguntas, respuestas y evaluación
- suscripciones — planes y registro de pagos
- orquestador del asistente — coordina el motor Prolog y el modelo de lenguaje

La clave de la API de OpenAI va en `.env`, nunca en el repositorio.
